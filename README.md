# Security Development Projects

A collection of small cybersecurity and networking tools built with C, C++, and Python.

Each project is stored in its own directory and includes its source code, documentation, usage examples, and tests.

## Projects

- [`cidr-toolkit`](./cidr-toolkit) — A C++ command-line tool for IPv4 subnet and CIDR calculations.
- [`logsentinel`](./logsentinel) — A Python command-line tool that analyses server logs and reports suspicious activity.

## Repository Structure

